# Traditional Food Sovereignty & Wellbeing — Aleutian Pribilof Islands

Public project website for the Traditional Food Sovereignty & Wellbeing COBRE pilot project,
a community-based approach to strengthening food sovereignty and wellbeing
across the Aleutian Pribilof Islands region of Alaska.

## Files

- `index.html` — homepage (mission, region, three aims, partners, contact)
- `rfsc.html` — dedicated page for the Regional Food Sovereignty Council (RFSC)
- `styles.css` — shared stylesheet used by both pages

No build tools, frameworks, or external dependencies — plain HTML/CSS, so it
loads fast even on limited bandwidth. Everything (including the logo/icons) is
inline SVG, so the site makes zero external network requests.

## Editing content

Open `index.html` or `rfsc.html` in any text editor and edit the text directly
inside the HTML tags. Shared colors, fonts, and layout live in `styles.css`.

## Before publishing

Content describing the region, the Tribes, and the Council should be reviewed
by APIA, ACSPI, and the Regional Food Sovereignty Council before this goes
live publicly. Several sections (e.g. "Who Sits on the Council") are explicitly
marked as draft/placeholder.
